# 한국 창업지원사업 사업계획서 양식

예비창업패키지, 초기창업패키지, 창업중심대학 등 한국 정부지원사업 HWP 양식을 채울 때 사용하는 참고 문서입니다.

## 기본 원칙

1. 원본 파일은 그대로 둡니다.
2. `작성본` 또는 `out` 같은 출력 폴더에 새 파일을 만듭니다.
3. 먼저 `kordoc`으로 문서를 읽어 제목, 표, 안내문을 파악합니다.
4. 대상 표는 제목과 렌더링 화면으로 확인합니다.
5. 표 안에는 심사위원이 바로 이해할 수 있게 짧은 개조식으로 작성합니다.
6. 표를 채운 뒤 기존 예시/가이드 문구가 남아 있으면 `business-plan-guides` 프리셋으로 제거합니다.
7. 최종 파일을 다시 읽거나 렌더링해서 문구 반영 여부를 확인합니다.

## 창업 아이템 개요 요약표

`창업 아이템 개요(요약)` 표는 보통 아래 매핑으로 작성합니다.

```json
{
  "section": 0,
  "parentParagraph": 7,
  "control": 0,
  "cleanPreset": "business-plan-guides",
  "removeNestedGuidesPreset": "business-plan-overview",
  "formatPreset": "business-plan-overview-compact",
  "cells": {
    "1": "아이템명",
    "3": "분야/분류",
    "5": "아이템 개요",
    "7": "문제 인식",
    "9": "실현 가능성",
    "11": "성장 전략",
    "13": "팀 구성"
  }
}
```

## 작성 기준

- `명칭`: 제품명만 짧게 작성합니다.
- `범주`: 산업 분야와 제품군을 함께 씁니다.
- `아이템 개요`: `[가치제안 제목]`을 먼저 쓰고, 설명 bullet 1~2개와 `핵심 기능`, `고객 혜택`을 이어 씁니다.
- `문제 인식`: `[문제 제목]`을 먼저 쓰고, 현재 불편, 기존 방식의 한계, 반복 비용/불만, 해결 방향을 씁니다.
- `실현 가능성`: `[구체화 제목]`을 먼저 쓰고, 시제품 구조, 개발 상태, 테스트 계획, 협력 자원을 씁니다.
- `성장 전략`: `[시장 목표 제목]`을 먼저 쓰고, 연도별 또는 단계별 시장 진입, 매출화, 확장 계획을 씁니다.
- `팀 구성`: `[실행 체계 제목]`을 먼저 쓰고, 대표자 역할, 협력사 역할, 테스트 매장/고객 검증 역할을 씁니다.

## 개요표 문장 구조

창업 아이템이 무엇이든 개요표는 아래 패턴을 기본으로 씁니다. 한 줄 요약만 넣으면 평가자가 아이템 구조를 이해하기 어렵습니다.

```text
[ 제품/서비스의 핵심 가치 또는 해결 결과 ]

- 무엇을 하는 제품/서비스인지
- 누구의 어떤 불편을 줄이는지

- 핵심 기능 : 작동 방식, 기술 요소, 제공 기능
- 고객 혜택 : 시간 절감, 비용 절감, 품질 개선, 매출 기여 등
```

최종 작성본은 표 셀 안에서 실제 줄바꿈 개조식으로 정리합니다. 기본은 `대괄호 주제 1줄 + 하이픈 항목 3~4줄`입니다.

각 셀은 `대괄호 주제 1개 + 하이픈 항목 최대 4개`를 기본으로 합니다. 페이지가 넘어가거나 글자가 빽빽하면 항목 수를 줄이고, 자세한 설명은 뒤쪽 본문 섹션으로 분리합니다.

최종 작성본은 검정색, 비기울임, 작은 글씨가 기본입니다. 파란색 안내문 스타일이나 기울임 스타일을 상속한 상태로 두지 않습니다. 다만 강조가 필요한 핵심 목표 1줄은 파란색/큰 글씨로 중앙 배치할 수 있습니다.

문제 인식은 아래처럼 씁니다.

```text
[ 목표 고객이 겪는 핵심 문제 ]

- 현재 업무/사용 과정에서 발생하는 불편
- 기존 방식이 실패하거나 비효율적인 이유
- 반복되는 시간, 비용, 품질, 고객 불만
- 본 아이템이 이 문제를 해결하는 방식
```

실현 가능성과 성장 전략은 아래처럼 씁니다.

```text
[ 현재 구현 상태와 구체화 계획 ]

- 시제품 또는 MVP의 핵심 구조
- 개발 완료/진행/예정 항목
- 테스트 고객, 협력사, 검증 지표
- 출시 전까지 남은 실행 과제
```

```text
[ 목표시장과 사업화 방향 ]

- 1단계 : 초기 고객군과 테스트 판매
- 2단계 : 유료화, 렌탈, 구독, 유지보수 등 수익 모델
- 3단계 : 프랜차이즈, B2B, 해외 등 확장 경로
```

## 예시문 제거

정부지원사업 양식은 표 셀 안에 파란색 예시문이나 중첩 안내 박스가 들어 있는 경우가 많습니다. 셀에 새 내용을 넣은 뒤에도 예시문이 남으면 제출본이 지저분해지므로 아래 방식으로 정리합니다.

JSON에 포함:

```json
{
  "cleanPreset": "business-plan-guides"
}
```

명령어에서 지정:

```bash
node skill/hwp-document-suite/scripts/hwp_fill_cells.mjs ./template.hwp ./out/draft.hwp --map ./cells.json --clean-preset business-plan-guides
```

예시문 제거만 따로 실행:

```bash
node skill/hwp-document-suite/scripts/hwp_clean_text.mjs ./draft.hwp ./out/cleaned.hwp --preset business-plan-guides
```

현재 프리셋은 예비창업패키지 사업계획서 개요표에 있는 대표적인 예시 문구와 안내 문구를 공백으로 바꿉니다. 중첩 표의 테두리나 빈 박스는 남을 수 있지만, 화면에 보이는 예시 텍스트는 제거됩니다.

빈 중첩 안내 표까지 제거하려면 `removeNestedGuidesPreset`을 함께 사용합니다.

```json
{
  "removeNestedGuidesPreset": "business-plan-overview"
}
```

Windows에서 한컴오피스 한글이 설치되어 있으면 이 프리셋이 COM 자동화로 개요표 안의 1x1 안내 표 컨트롤을 삭제합니다. 한글 창이나 보안 확인창이 떠 있으면 자동화가 멈출 수 있으므로 닫고 다시 실행합니다.

## 좌표 찾기

공통 좌표가 맞지 않으면 아래 순서로 찾습니다.

1. 근처 페이지를 렌더링합니다.

```bash
npx --yes k-skill-rhwp render input.hwp --page 2 --format html
```

2. 복사본에 안전하게 테스트 문구를 넣습니다.

```bash
npx --yes k-skill-rhwp set-cell-text input.hwp probe.hwp --section 0 --parent-paragraph 7 --control 0 --cell 0 --text PROBE
```

3. `probe.hwp`를 다시 렌더링하거나 읽어서 `PROBE`가 들어간 위치를 확인합니다.

4. 위치가 맞으면 `hwp_fill_cells.mjs`로 실제 작성본을 만듭니다.

## 한계

- 현재 `k-skill-rhwp` 편집 경로는 텍스트 입력은 가능하지만 글자색을 직접 지정하는 옵션은 제한적입니다.
- 중첩 안내 표 컨트롤 삭제는 Windows + 한컴오피스 한글 COM 환경에서 가장 안정적으로 동작합니다.
- 개요표 포맷 정리는 `formatPreset: business-plan-overview-compact`를 사용합니다.
- 원본 셀이 이미 파란색 안내문 스타일이면 새 텍스트가 해당 스타일을 일부 상속할 수 있습니다.
- HWPX 입력은 편집 경로에서 HWP로 저장될 수 있습니다.
