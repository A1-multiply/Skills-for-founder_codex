# A1-HWP-SKILL 스킬 패키지

이 폴더는 Codex용 HWP/HWPX 스킬 본체입니다.

## 스킬 이름

- `A1-HWP-SKILL`

## 사용

- `@A1-HWP-SKILL`로 문서를 읽고 수정합니다.
- 기본 생성 템플릿은 `skill/A1-HWP-SKILL/assets/clean-overview-template.hwp`입니다.
- `../Sample/창업아이템 개요부분.hwp`는 원본 보관용입니다.

## 설치

- 저장소를 내려받은 뒤 `install.ps1` 또는 `install.sh`를 실행합니다.
- 설치가 완료되면 `A1-HWP-SKILL` 스킬이 등록됩니다.
