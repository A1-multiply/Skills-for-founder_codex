# Example Prompts

## Read And Summarize

```text
Use hwp-document-suite to read this HWP file. Summarize the full document, including headings, body content, tables, images, and overall structure.
```

```text
Use hwp-document-suite to extract this HWPX file as Markdown and JSON. Then explain the section structure and list all tables.
```

## Table Analysis

```text
Use hwp-document-suite to inspect this document and tell me what tables exist, what each table appears to mean, and whether any cells are empty.
```

## Editing

```text
Use hwp-document-suite to replace every "2025" with "2026" in this HWP file. Save the result as a new file and verify it afterward.
```

```text
Use hwp-document-suite to find the paragraph containing "지원 대상" and insert a short note after it in a new HWP output file.
```

```text
Use hwp-document-suite to create a 3 by 4 table after the first paragraph and fill the first cell with "Total".
```

## Startup Overview

```text
Use hwp-document-suite to fill only the 창업 아이템 개요(요약) table in this HWP.
Ask me briefly about average line count, year usage, bullet/prose style, alignment, font size, top padding, emphasis color, and whether to generate images unless I say to use defaults.
```

```text
이 HWP의 창업아이템 개요부분만 작성해줘. 그냥 기본값으로 해.
아이템명은 사용자가 제공한 명칭으로 넣고, 범주는 네가 판단해.
```

```text
팀 구성은 실제 수행 가능성이 보이게 써줘. 실명은 쓰지 말고, 관련 분야 경력자와 유통/검증 파트너처럼 역할과 경력 중심으로 작성해.
```
